# Resumen del Sprint

Durante las 20 reuniones Daily Scrum se realizó seguimiento continuo al progreso del Sprint 02.

Los principales temas tratados fueron:

- Desarrollo del sistema de autenticación.
- Implementación de formularios.
- Integración de Server Actions.
- Configuración de Embeddings.
- Base de datos vectorial.
- Consultas semánticas.
- Respuestas de Inteligencia Artificial.

## Principales impedimentos encontrados

- Ausencia ocasional de algunos integrantes del equipo.
- Conflictos al integrar ramas mediante Git.
- Dificultades iniciales utilizando `git rebase`.
- Problemas durante las migraciones de Prisma.
- Errores de autenticación durante las primeras pruebas.
- Uso de mayor tiempo propuesto para la finalizacion del sprint (extender la deadline)

Todos los inconvenientes fueron solucionados antes de finalizar el Sprint, permitiendo cumplir los objetivos establecidos.
