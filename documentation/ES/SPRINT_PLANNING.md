# Sprint 0 - Setup y Planeación

## Objetivo

Preparar la infraestructura técnica y organizacional necesaria para iniciar el desarrollo de LlegoYa.

## Duración

Semana 1

## Actividades realizadas

### Infraestructura

* Creación del repositorio GitHub.
* Configuración inicial de Git Flow.
* Definición de convenciones de commits.

### Gestión

* Creación del proyecto Jira.
* Configuración del Product Backlog.
* Creación de épicas.

### Arquitectura

* Definición de arquitectura Fullstack.
* Selección del stack tecnológico.
* Definición de estructura de carpetas.

### Planeación

* Definición de módulos principales.
* Definición de vistas iniciales.
* Definición de alcance MVP.

## Resultado

Proyecto listo para iniciar Sprint 1.
