# Sprint 02 Retrospective

## General Information

| Field        | Value                                             |
| ------------ | ------------------------------------------------- |
| Sprint       | 02                                                |
| Participants | Scrum Master, Product Owner, and Development Team |

---

# Objective

Reflect on Sprint 02 development to identify strengths, challenges, and improvement opportunities to optimize team performance in upcoming sprints.

---

# What went well?

- All planned user stories were completed.
- The team successfully implemented the authentication system.
- New knowledge was gained around Server Actions and vector databases.
- Communication between team members improved compared to Sprint 01.
- Project documentation remained up to date throughout development.

---

# What did not go so well?

- Frequent Git conflicts occurred during branch integration.
- Some team members could not attend certain meetings due to academic commitments.
- Initial pgvector setup took longer than estimated.
- Some tasks had to be reassigned due to workload distribution issues.

---

# Lessons Learned

During this sprint, the team identified several key areas for improving the development process:

- Better task distribution planning.
- Make smaller and more frequent commits.
- Integrate changes into the repository more regularly.
- Review official documentation before implementing new technologies.
- Communicate any blocker proactively so it does not slow down the sprint.

---

# Improvement Actions

| Action                                          | Responsible      |
| ----------------------------------------------- | ---------------- |
| Improve Git branch strategy                     | Entire team      |
| Perform code reviews before merging             | Development Team |
| Schedule follow-up meetings when blockers arise | Scrum Master     |
| Increase testing before finalizing each story   | Development Team |
| Keep documentation up to date                   | Entire team      |

---

# Practices to Maintain

The team agreed to continue with:

- Daily Scrum meetings.
- Organization via Jira.
- GitHub for version control.
- Continuous project documentation.
- Constant communication between team members.

---

# Conclusion

Sprint 02 represented significant growth for both the project and the development team. Despite some technical and organizational challenges, they were overcome through collaborative work and problem-solving.

The experience gained will help the team approach Sprint 03 with better organization, deeper knowledge of the tools, and more precise task planning.
